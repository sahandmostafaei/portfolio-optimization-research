# Data

The empirical analysis is designed to use historical monthly total-return
data for the specified ETF universe.

The repository does not redistribute third-party market-data files.

The research design specifies the required data construction and validation
procedures, including the use of historical adjusted prices/total returns,
monthly return formation, and strict information-timing controls.

The empirical results section will only be populated after the underlying
historical data have been obtained and the complete analysis pipeline has
been executed and audited.
