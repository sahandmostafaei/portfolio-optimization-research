# Results

The manuscript currently contains a finalized empirical research design but
does not report fabricated numerical findings.

The intended analysis will evaluate:

- annualized return
- annualized volatility
- Sharpe ratio
- Sortino ratio
- maximum drawdown
- VaR
- CVaR
- turnover
- transaction costs
- concentration
- effective number of holdings
- market-regime performance
- factor exposures
- robustness across estimation windows and implementation assumptions

Numerical results will only be added after the complete out-of-sample
pipeline has been executed using historical market data.
